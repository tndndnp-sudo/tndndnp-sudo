# панель управления мной

Одна страница, на которой живёт моя учёба, игры и бытовуха: расписание с звонками,
оценки, домашка, таймер 25/5, библиотека игр с честными часами, привычки, деньги
и записки на вечер.

Ничего не собирается и никуда не отправляется: чистый html + css + js, все отметки
лежат в `localStorage` этого браузера. Весит ~35 КБ в gzip, шрифт — единственный
внешний запрос. Если зайти сюда без интернета (после первого визита), панель
продолжит работать — за это отвечает `sw.js`.

## запустить

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

Сервер нужен только ради нормальных путей и сервис-воркера: открыть `index.html`
двойным кликом тоже можно, но без офлайн-режима.

## что где менять

| файл | зачем |
| --- | --- |
| `js/data.js` | **всё содержимое**: расписание, оценки, игры, привычки, деньги, ссылки |
| `index.html` | каркас секций |
| `css/style.css` | вид, градиенты, анимации, адаптив |
| `js/ui.js` | тема, залипающее меню, часы, прожектор за курсором, cmd+k |
| `js/study.js` | расписание, домашка, оценки, даты, таймер |
| `js/play.js` | фильтры игр, вишлист, катки |
| `js/life.js` | привычки, режим дня, кошелёк, записки |
| `sw.js` | кэш, чтобы работало офлайн |

Хочешь другие данные — правь только `js/data.js`, списки отрисуются сами.
Даты пишутся как `2026-11-18`, в домашке `due` можно ставить `+1` (завтра).

## как это выглядит

- тёмная и светлая темы, переключение — круговым раскрытием (View Transitions),
  выбор запоминается; на телефоне лист меню на весь экран со ступенчатой анимацией
- пилюля в меню сама ездит под активным пунктом, разделы подсвечиваются по скроллу
- `ctrl + K` — быстрый поиск по разделам и действиям (на macOS покажется `⌘ K`)
- карточки наклоняются за курсором, фон-градиент медленно дышит, при скролле секции
  проявляются; всё это выключается, если в системе стоит «уменьшить движение»
- на телефоне нет ховер-эффектов, тяжёлых блюров и анимаций фона — чтобы не грелся

## выложить на GitHub Pages

Настроить → Pages → Source: Deploy from a branch → `main` / корень репозитория.
`.nojekyll` уже лежит, чтобы сборка не трогала файлы.

## сброс

Данные сидят в ключе `tnd:` в DevTools → Application → Local Storage. Удалишь ключ —
вернутся исходные списки из `js/data.js`.
